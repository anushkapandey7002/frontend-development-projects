### 2. Campus Connect — Responsive Landing Page
A landing page concept for a student platform to discover campus events, clubs, workshops, hackathons, and opportunities.

**Technologies:** HTML5, CSS3, JavaScript

**Features:**
- Responsive desktop and mobile layout
- Mobile hamburger navigation
- Event and opportunity sections
- Navigation links and call-to-action buttons

**Run locally:** Open `responsive-landing-page/index.html` using VS Code Live Server.
