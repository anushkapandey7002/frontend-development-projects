# Frontend Development Projects

A collection of my frontend development projects built while learning and practising web development.

## Projects

### 1. Personal Portfolio Website

A responsive personal portfolio website showcasing my introduction, skills, projects, and contact information.

**Features**
- About, Skills, Projects, and Contact sections
- Responsive navigation menu
- Mobile-friendly layout
- CSS Grid and Flexbox
- Hover effects and smooth scrolling

**Technologies:** HTML5, CSS3, JavaScript

**Project folder:** `personal-portfolio/`

## Setup Instructions

1. Clone this repository:

   `git clone https://github.com/anushkapandey7002/frontend-development-projects.git`

2. Open the `personal-portfolio` folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
